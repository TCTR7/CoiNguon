# Cội Nguồn

PWA quản lý gia phả và hỗ trợ tổ chức giỗ cho gia đình/chi họ.

## Trạng thái

Đã có frontend mẫu theo phong cách Gia phả đương đại, điều hướng, tìm hồ sơ và thử phản hồi thiệp. Các trang gia phả/lịch/thiệp dùng dữ liệu giả. Workspace /dong-ho đã có đăng nhập local, quản lý dòng họ/thành viên, link đăng ký chung có admin duyệt, hồ sơ gia phả, quan hệ, đề nghị liên kết/sửa, lịch giỗ/chủ sự, thiệp khách và xác nhận tham dự theo hộ qua Emulator và API local.

Chạy npm ci rồi npm run dev để mở ứng dụng local. Để thử /dong-ho, chạy thêm npm run emulators ở terminal thứ hai. Lệnh kiểm tra và emulator nằm trong [DEVELOPMENT.md](docs/DEVELOPMENT.md).
